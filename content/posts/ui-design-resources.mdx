做界面时最浪费时间的，往往不是写 CSS，而是**不知道该看什么**。打开 Dribbble 收藏一百张卡，打开 Figma 下一堆 Kit，回到自己的项目——还是默认灰底、默认圆角、默认三列。

问题通常不在「资源不够」，而在**没有匹配当前项目气质的学习路径**。暗色沉浸站和白底 SaaS 后台，该学的东西完全不同。

## 先定：你的项目到底在学什么

动手搜之前，用三五句话写清风格，例如：

- 暗黑 / 黑金 / 博物馆档案感  
- 沉浸式 Hero、强叙事图片  
- 衬线标题 + 克制标签  
- 玻璃卡片可以有，但不能廉价  

有了方向，后面的关键词和站点才有筛选标准。没有方向时，任何「好看」都会把你拽回模板脸。

## 四步学习路线

### 第一步：学视觉氛围

**优先看**：[Awwwards](https://www.awwwards.com/websites/)、[Godly.design](https://godly.design/)、[Pinterest](https://www.pinterest.com/)

观察：

- 背景如何制造纵深，而不是一块死黑  
- 首屏如何「压住」整页  
- 图文如何叠层，而不是图 + 字两截  
- 暗色如何避免发灰、发脏  

Pinterest 适合做 **Moodboard**（先攒 20–50 张定情绪），不适合直接抄交互。

### 第二步：学布局结构

**优先看**：[Land-book](https://land-book.com/)、Godly、[Mobbin](https://mobbin.com/)

观察：

- 导航密度与层级  
- Hero 之后如何接内容（统计、列表、画廊）  
- 卡片网格节奏：对齐还是刻意错落  
- 搜索 / 筛选 / 详情如何组织信息  

Land-book 偏落地页节奏；Mobbin 偏真实产品流程（列表、弹窗、状态）。

### 第三步：学字体排版

**优先看**：[Typewolf](https://www.typewolf.com/)、[Fonts In Use](https://fontsinuse.com/)、[Google Fonts](https://fonts.google.com/)

观察：

- 标题与正文如何配对（气质是否同一句话）  
- 大标题字距、小标签 uppercase  
- 行高与次要文字颜色（别全用纯白）  

不知道「这种调子该用什么字」时，Fonts In Use 比盲目翻 Google Fonts 有效。

### 第四步：学设计系统与可用性

**优先看**：[Material Design](https://m3.material.io/)、[Apple HIG](https://developer.apple.com/design/human-interface-guidelines/)、[Figma Community](https://www.figma.com/community)

观察：

- 按钮 / 输入 / 弹窗的状态  
- 间距与颜色是否可 token 化  
- 组件如何命名与复用  

灵感站解决「想成为什么样」；规范站解决「点下去会不会翻车」。

## 站点速查（按用途）

| 用途 | 站点 | 怎么用 |
|------|------|--------|
| 高级网页视觉、实验布局 | [Awwwards](https://www.awwwards.com/websites/) | 搜 dark / editorial / immersive / museum |
| 真实高质量网页案例 | [Godly.design](https://godly.design/) | 拆首屏、卡片、导航整页结构 |
| 落地页节奏与分区 | [Land-book](https://land-book.com/) | 看 Hero → Features → Gallery → Footer |
| 产品交互与信息架构 | [Mobbin](https://mobbin.com/) | 学筛选、详情、表格、状态 |
| 字体气质与搭配 | [Typewolf](https://www.typewolf.com/) | 抄的是层级关系，不是某个免费字体名 |
| 真实用字案例 | [Fonts In Use](https://fontsinuse.com/) | 展览、书籍、品牌网页对照 |
| 规范与组件 | Material / HIG | 补交互基本功 |
| 视觉碎片灵感 | [Dribbble](https://dribbble.com/) | 慎用：强视觉 ≠ 可上线 |

## 搜索关键词可以这样写

把项目气质拆成英文关键词，比搜「好看的网站」有效得多：

```text
dark museum website
black gold web design
cinematic landing page
immersive storytelling website
editorial web design
gothic editorial website
dark glassmorphism UI
luxury black gold UI
```

Awwwards / Dribbble 上用这些词，命中率会明显高于 `best ui`。

## 刻意少看什么

时间有限时，建议**后看或少看**：

- 普通后台管理模板  
- 千篇一律的白底 SaaS 官网  
- 只有炫技动效、没有信息结构的页面  
- 纯概念稿、无法落到真实流程的 Dribbble 单卡  

不是它们「差」，而是它们**训练的是另一套肌肉**。你要做的是氛围型、叙事型站点时，先看错样本，审美会被拉歪。

## 最小收藏夹：只留五个

真没空就盯这五个：

1. **Awwwards** — 视觉上限  
2. **Godly.design** — 真实网页落地感  
3. **Land-book** — 商业落地页节奏  
4. **Typewolf** — 字体与排版  
5. **Mobbin** — 功能与交互细节  

每周拆 **1 个整页** 比收藏 50 张截图有用：写清「背景三层怎么分、标题字号阶梯、主按钮为什么长这样」。

## 和写代码的关系

灵感站不会自动变成好界面。更好的闭环是：

1. Moodboard 定情绪  
2. 拆 1–2 个参考站的结构与字阶  
3. 用设计系统思维落到 token（色、间距、字重）  
4. 再让 AI 写代码——并挂上审美约束技能，避免又滑回默认皮  

资源解决「看过什么」；约束解决「模型敢不敢乱画」。两者一起用，才像手艺，而不是碰运气。

## 小结

UI 学习资源很多，**路径比书单更重要**：氛围 → 布局 → 字体 → 系统。先对准自己的项目气质，再打开浏览器；否则收藏夹只会越来越满，界面还是老样子。
